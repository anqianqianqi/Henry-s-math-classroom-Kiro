# Henry's Math Classroom — TA Agent

This directory contains the design and implementation of an AI Teaching Assistant agent
for Henry's Math Classroom platform.

## Purpose

The TA agent is meant to assist students with math challenges, provide hints,
give feedback on submissions, and support Henry (the teacher) in managing the classroom.

## Status

🟡 Design phase — discussing architecture and capabilities.

## Notes

- See this directory for all agent-related code, prompts, and configuration.
- The main classroom app lives at the root of the repo.
